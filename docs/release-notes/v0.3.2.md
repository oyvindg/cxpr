# cxpr 0.3.2

This public pre-1.0 release expands the model, optimization, tooling, and typed
execution surfaces while preserving the public shared-library major version.

Highlights:

- model invariants with `assert`, optimizer dimensions/objectives, lexicographic
  ranking, candidate pruning, and host accelerator integration;
- a standalone CXCU optimizer adapter and CUDA parity coverage;
- exact `int64` arithmetic, bindings, history, resampling, debug metadata, and
  checked generated-C results;
- document tooling, evaluation-flow snapshots, language-service metadata, and
  VS Code/WASM analyzer integration;
- flow-field/pathfinding primitives and generic host optimizer APIs;
- compile-time validation of imported-model named arguments and one canonical
  `samples` name for sample-count arguments.

Consumers should apply normal `0.x` compatibility expectations and allow for
source/API adjustments in later minor releases.

See the [changelog](../../CHANGELOG.md#032---2026-11-01) and the
[public API documentation](../api/README.md) for the complete contract.
